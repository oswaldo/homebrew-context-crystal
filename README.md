# Homebrew Context Crystal

Official Homebrew Tap for [Context Crystal][repo] (`ccrystal`).

Deterministic context preservation, DAG provenance, and runtime
orchestration for AI coding entities.

## Installation

Install directly with Homebrew:

```bash
brew install oswaldo/context-crystal/ccrystal
```

Or add the tap first:

```bash
brew tap oswaldo/context-crystal
brew install ccrystal
```

## Upgrade

To upgrade to the latest release:

```bash
brew update
brew upgrade ccrystal
```
